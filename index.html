04 / Standards

How the code is written.

A clean workspace is not a preference. It is how projects stay fast to change a year later.

A

PascalCase only

One naming convention, everywhere. Player.Inventory:Add(), never a mix.

B

Compressed by default

No dead lines, no filler. Every script reads tight and does one job well.

C

Modular infrastructure

Systems plug in and out cleanly, so features ship without rewriting the core.

D

Low latency first

Batched remotes, delta replication and buffers, so players feel the game respond.
