Meticulous by default.

Every system has its place. Four rules run through every codebase I touch.

  1. 01

    Consistency

    PascalCase throughout. One naming style, every script, every project.

  2. 02

    Conciseness

    Compact implementation without giving up readability. Nothing left over.

  3. 03

    Modularity

    Systems are isolated and reusable, so they drop into a project and come out cleanly.

  4. 04

    Responsiveness

    Networking designed around how fast the game feels to the player.
